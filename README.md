# TPs Python — initiation à la programmation

Série de 16 exercices d'initiation à Python : entrées/sorties, conditions, boucles, chaînes de caractères et premières structures de données.

## Exercices

| Fichier | Sujet |
|---------|-------|
| `exo0.py` | Nombre de taxis nécessaires (division entière, reste) |
| `exo1.py` | Calcul du prix de billets avec cas particulier |
| `exo2.py` | Conditions sur une température |
| `exo3.py` | Remise selon le jour de la semaine |
| `exo4.py` | Comparaison de deux âges |
| `exo5.py` | Comparaison des temps de deux coureurs |
| `exo6.py` | Décomposition d'un prix en dinars / centimes |
| `exo7.py` | Année bissextile |
| `exo8.py` | FizzBuzz |
| `exo9.py` | `dataclass` : modélisation de villes |
| `exo10.py` | Détection de palindrome |
| `exo11.py` – `exo12.py` | Dessin de lignes et rectangles en `#` |
| `exo13.py` | Lecture de chaînes en boucle jusqu'à une entrée vide |
| `exo14.py` | Centrage d'un texte dans un cadre |
| `exo15.py` | Recherche de voyelles dans une chaîne |

## Exécution

```bash
python exo8.py
```

Python 3.7 ou plus récent ; aucune dépendance externe.
